# Oleg Bukhtoiarov - Portfolio Website

A personal portfolio website showcasing my professional experience as an ABAP developer with expertise in SAP systems, Oracle Siebel CRM, and web development technologies.

## 🌟 About

Hello! I'm Oleg Bukhtoiarov, a 32-year-old ABAP developer with over 10 years of professional experience. This portfolio website highlights my journey in software development, from my early work with Oracle Siebel CRM to my extensive experience with SAP ABAP development and modern web technologies.

## 🚀 Features

- **Responsive Design**: Optimized for desktop and mobile viewing
- **Interactive Projects Section**: Click on company or project headers to expand/collapse details
- **Skills Showcase**: Interactive skill icons with links to relevant documentation
- **Contact Form**: Functional contact form for professional inquiries
- **Clean Navigation**: Smooth navigation between sections and pages

## 🛠️ Technologies Used

### Backend/ERP Development
- **ABAP**: Primary programming language for SAP development
- **SAP ECC & S/4HANA**: Enterprise resource planning systems
- **SAP HANA**: In-memory database technology
- **SAP OData**: RESTful API for SAP data access
- **SAPUI5**: JavaScript framework for SAP applications
- **Oracle Siebel CRM**: Customer relationship management system

### Web Development
- **HTML5**: Semantic markup structure
- **CSS3**: Responsive styling with Flexbox and Grid
- **Vanilla JavaScript**: Interactive functionality without frameworks
- **Google Fonts**: Typography enhancement

## 🏃‍♂️ Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portfolioProject.git
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolioProject
   ```

3. Open `index.html` in your web browser to view the portfolio

- **Projects**: Click on company names or project titles to reveal detailed information

- **Contact**: Fill out the contact form to send inquiries
